# Contributing

This repository is intended as an educational/open engineering project.

## Before submitting a change

- Keep calculations explicit.
- Add tests for numerical changes.
- State units in function names, arguments or documentation.
- Preserve model provenance.
- Do not silently change a reference system or correction convention.
- Do not present screening calculations as operationally qualified calculations.

## Numerical changes

For changes affecting engineering equations:

1. Document the equation.
2. State assumptions.
3. Add at least one known-value test.
4. Explain any reference convention.
5. Identify the source/standard where applicable.
